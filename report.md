# Прогноз мощности парогазовой установки

## Короткий вывод

На обычных температурных условиях MLP точнее линейной регрессии. На полностью отложенном жарком диапазоне лучшей оказалась сеть с **tanh**: RMSE **4,45 МВт**, против **5,09 МВт** у ReLU и **6,24 МВт** у линейной модели. Все три модели при фиксированных остальных параметрах показывают физически ожидаемое снижение мощности с ростом температуры; у сетей на проверенной кривой нет локальных разворотов вверх.

## Данные и проверка

В наборе **9 568 часовых наблюдений** работы станции на полной нагрузке. По температуре воздуха (AT, °C), вакууму на выходе паровой турбины (V, см рт. ст.), атмосферному давлению (AP, мбар) и относительной влажности (RH, %) прогнозируется чистая электрическая мощность (PE, МВт). Источник — набор [Combined Cycle Power Plant от UCI](https://archive.ics.uci.edu/dataset/294/combined%2Bcycle%2Bpower%2Bplant).

Для проверки обобщения в тест отложены все строки с температурой **не ниже 26,79 °C** — верхние 20% по AT, **1 915 наблюдений**. Остальные строки разделены на обучающую часть (6 122) и внутреннюю проверку для настройки (1 531). Порог определяется только по входной температуре, целевая мощность теста при выборе порога не использовалась.

MLP ReLU и tanh имеют одинаковую архитектуру **32–16**. Сила L2-регуляризации выбиралась из трёх значений на внутренней проверке; затем сеть переобучалась на всех 7 653 наблюдениях ниже температурного порога. Жаркий тест не участвовал ни в выборе архитектуры, ни в подборе регуляризации.

## Сравнение качества

| Модель | Проверка: RMSE / MAE / R² | Жаркий тест: RMSE / MAE / R² |
|---|---:|---:|
| Линейная регрессия | 4,25 / 3,39 / 0,927 | 6,24 / 5,02 / −0,508 |
| MLP ReLU | **3,77 / 2,86 / 0,943** | 5,09 / 4,17 / −0,005 |
| MLP tanh | 3,82 / 2,91 / 0,941 | **4,45 / 3,60 / 0,231** |

Ошибки мощности указаны в МВт. На внутренней проверке ReLU немного лучше tanh, но на неиспользованных жарких условиях tanh переносится лучше. Так как горячий тест оставался закрытым при настройке, это показывает различие поведения моделей вне диапазона обучения, а не результат подбора под тест.

По температурным интервалам ошибка всех моделей растёт в жарком хвосте. В самых горячих 5% данных (30,92–37,11 °C) RMSE составляет **8,29 МВт** у линейной модели, **6,21 МВт** у ReLU и **4,92 МВт** у tanh. Значит, сеть с tanh лучше сохраняет точность на крайних значениях, хотя её ошибка там тоже выше, чем на более прохладном участке.

## Зависимость от температуры

Для графика температуры остальные входы зафиксированы на медианах обучающих наблюдений: V = **45,17 см рт. ст.**, AP = **1014,01 мбар**, RH = **78,31%**. На всём показанном диапазоне 1,81–37,11 °C все три прогноза монотонно уменьшаются. Полное изменение составляет примерно −73,4 МВт для линейной модели, −71,0 МВт для ReLU и −56,1 МВт для tanh. Это частный профиль модели при фиксированных погодных параметрах, а не универсальная паспортная характеристика станции.

## Вывод и ограничения

В этом эксперименте MLP действительно улавливает нелинейность и даёт лучший прогноз на жарком хвосте, особенно tanh. При этом вывод относится только к данным станции на **полной нагрузке** за 2006–2011 годы. Его нельзя трактовать как характеристику работы установки при частичной нагрузке или переносить на другую электростанцию без отдельной проверки.

В ZIP были пять листов с пятью перемешиваниями одного набора. В анализ включён один полный лист, чтобы не считать те же наблюдения пять раз. Все шаги воспроизводятся командой `python analysis.py`; подбор проходит только на данных ниже порога, а горячий тест оценивается после завершения настройки.
