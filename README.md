# Мощность парогазовой установки — вариант 5

Сравнение линейной регрессии и двух многослойных персептронов (ReLU и tanh) для прогноза чистой электрической мощности по четырём погодным измерениям.

## Запуск

Нужны Python 3.10+ и NumPy:

```powershell
python -m pip install -r requirements.txt
python analysis.py
```

Скрипт использует все 9 568 записей. Верхние 20% температурных условий отложены для итогового теста; архитектура и регуляризация MLP подбираются только на оставшейся части. Результаты и графики записываются в `results/` и `figures/`.

## Файлы

- `analysis.py` — линейная модель, MLP с ReLU и tanh одинаковой архитектуры 32–16, разделение горячего хвоста, настройка на валидации и расчёт метрик.
- `data/ccpp.csv` — один полный вариант набора данных из предоставленного архива.
- `data/Readme.txt` и `data/README.md` — описание источника, признаков и единиц измерения.
- `report.md` — выводы простым языком.
- `figures/` — зависимость мощности от температуры и ошибка по температурным интервалам.
- `results/` — метрики, настройки модели, табличные кривые и ошибки по интервалам.

Тестовая часть выбрана только по температуре входного признака, без просмотра целевой мощности. Она представляет наиболее жаркие условия; выводы относятся к данным установки на полной нагрузке.
